# YouMe

Video share, reels, feed aur inbox — ek alag app. Seetal system se iska koi lena-dena nahi.

**Live:** https://bhupendarsingh785.github.io/youme/

## Andar kya hai
- Home feed + stories
- Reels (swipe, double-tap like, filters)
- Create (post / reel / poll)
- Inbox (Instagram jaisa — search, unread, chat)
- Lens (camera + 12 filters + AR masks)
- Alerts, Profile, Wallet (demo)

## Sach
- Data abhi phone me (localStorage) — public feed ke liye backend baad me
- AI jawab free service se (45s limit)
