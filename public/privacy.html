Privacy — tumhara data

Aakhri badlav: 12 November 2026

Ye ek shuruaati template hai. App ko public karne se pehle kisi vakil se dikhwa lo aur neeche [apna email] ki jagah asli contact daalo.

Hum kya rakhte hain

  • Account: username, tumhara naam, aur password (sirf scrypt hash ke roop me — asli password hum kabhi nahi dekh sakte). Recovery code bhi sirf hash hota hai.
  • Tumhara content: post, photo, replies, likes.
  • Message (DM): tumhare aur samne wale ke beech ke message.
  • Safety: kisko block kiya, kis post ko report kiya.
  • Feed ke liye: tum kin creators ke post like/reply/share karte ho, uska ek number. Isse feed tumhari pasand ke hisab se sajti hai. Settings me "Algorithm reset" se ye saaf ho jata hai.
  • Coins: kitne coins mile (abhi sirf demo, asli paise nahi).

Hum kya nahi lete

Phone number, email, location, contacts — kuch nahi. Is server par koi vigyapan (ads) ya tracker nahi hai.

Dhyan rakhne wali baatein

  • DM end-to-end encrypted nahi hain. Wo server par padhne layak roop me rehte hain, to server chalane wala unhe technically dekh sakta hai. Bahut zaroori ya nijee baat DM me mat bhejo.
  • "YouMe AI" chat: is chat me jo likhte ho wo jawab banane ke liye bahari seva pollinations.ai ko bheja jaata hai.
  • Lens / camera: camera tumhare phone me hi chalta hai. Photo tabhi server par jaati hai jab tum "post" dabate ho. Chehra pehchanne wala model jsDelivr aur Google Storage se download hota hai, isliye unhe tumhara IP dikh sakta hai.
  • Jis par tum ne chhota data phone me (localStorage) rakha hai, wo sirf tumhare browser me rehta hai.

Delete aur backup

Settings → "Account hamesha ke liye delete" se tumhare post, photo, replies aur message hat jaate hain. Server ke backup me ek purani copy kuch din (shuruaat me 7 din) tak reh sakti hai, phir apne aap mit jaati hai.
